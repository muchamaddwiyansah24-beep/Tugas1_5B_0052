# Tugas 1 - Dart Dasar

Repository ini berisi 4 program latihan dasar menggunakan bahasa pemrograman Dart.

## 1. Persegi Panjang
Program untuk menghitung luas dan keliling persegi panjang menggunakan fungsi `luas()` dan `keliling()`.

File: `latihan1_persegi_panjang.dart`

## 2. Rata-rata dan Grade
Program untuk menghitung nilai rata-rata dan menentukan grade berdasarkan nilai yang diperoleh.

File: `latihan2_rata_rata_grade.dart`

## 3. FizzBuzz
Program untuk menampilkan angka 1 sampai 20 dengan aturan Fizz, Buzz, dan FizzBuzz.

File: `latihan3_fizzbuzz.dart`

## 4. Class Mahasiswa
Program untuk menampilkan informasi mahasiswa berupa nama, NIM, dan IPK, serta memilih mahasiswa dengan IPK minimal 3.5.

File: `latihan4_mahasiswa.dart`
